## 3. 核心设计思想

### 3.1 场景模式 (Scene Pattern)

**设计目标**：实现游戏不同状态（菜单、选择、对战）之间的平滑切换

**实现方式**：
```cpp
// 抽象场景基类 (scene.h)
class Scene {
public:
    virtual void on_enter() {}    // 进入场景时调用
    virtual void on_update(int delta) {}  // 每帧更新
    virtual void on_draw(const Camera& camera) {}  // 渲染
    virtual void on_input(const ExMessage& msg) {}  // 输入处理
    virtual void on_exit() {}     // 退出场景时调用
};
```

**核心优势**：
- ✅ **解耦**：每个场景逻辑独立，互不干扰
- ✅ **可扩展**：新增场景只需继承 Scene 基类
- ✅ **生命周期管理**：统一的状态转换机制

### 3.2 游戏循环架构

```cpp
// main.cpp:213-257
while (true) {
    // 1. 计算帧时间
    DWORD frame_start_time = GetTickCount();

    // 2. 处理输入
    while (peekmessage(&msg)) {
        scene_manager.on_input(msg);
    }

    // 3. 更新逻辑
    DWORD delta_tick = current_tick_time - last_tick_time;
    scene_manager.on_update(delta_tick);

    // 4. 渲染画面
    cleardevice();
    scene_manager.on_draw(main_camera);
    FlushBatchDraw();

    // 5. 帧率控制
    if (frame_delta_time < 1000 / FPS)
        Sleep(1000 / FPS - frame_delta_time);
}
```

**设计亮点**：
- 固定 60 FPS 帧率
- Delta time 机制确保不同帧率下游戏速度一致
- 双缓冲消除闪烁

### 4.3 动画系统 (Animation)

**文件**：`animation.h`

```cpp
class Animation {
public:
    void set_atlas(Atlas* new_atlas) {
        reset();
        atlas = new_atlas;  // 绑定图集
    }

    void set_interval(int ms) {
        interval = ms;  // 设置帧间隔
    }

    void on_update(int delta) {
        timer += delta;
        if (timer >= interval) {
            timer = 0;
            idx_frame++;  // 切换到下一帧
            if (idx_frame >= atlas->get_size()) {
                idx_frame = is_loop ? 0 : atlas->get_size() - 1;
                if (!is_loop && callback)
                    callback();  // 动画结束回调
            }
        }
    }

    IMAGE* get_frame() {
        return atlas->get_image(idx_frame);
    }

private:
    Atlas* atlas = nullptr;
    int timer = 0;
    int interval = 0;
    int idx_frame = 0;
    bool is_loop = true;
    std::function<void()> callback;
};
```

**设计优势**：
- 简洁的帧动画实现
- 支持循环/非循环模式
- 回调机制实现动画结束事件

### 4.5 计时器系统 (Timer)

```cpp
class Timer {
public:
    void set_wait_time(int val) {
        wait_time = val;
    }

    void set_one_shot(bool flag) {
        one_shot = flag;  // 是否只触发一次
    }

    void set_callback(std::function<void()> callback) {
        this->callback = callback;
    }

    void pause() {
        paused = true;
    }

    void resume() {
        paused = false;
    }

    void on_update(int delta) {
        if (paused) return;
        pass_time += delta;
        if (pass_time >= wait_time) {
            if ((!one_shot || (one_shot && !shotted)) && callback)
                callback();
            shotted = true;
            pass_time = 0;
        }
    }

private:
    int pass_time = 0;
    int wait_time = 0;
    bool paused = false;
    bool shotted = false;
    bool one_shot = false;
    std::function<void()> callback;
};
```

```cpp
// 图像水平翻转
inline void flip_image(IMAGE* src, IMAGE* dst) {
    int w = src->getwidth();
    int h = src->getheight();
    Resize(dst, w, h);
    DWORD* src_buffer = GetImageBuffer(src);
    DWORD* dst_buffer = GetImageBuffer(dst);
    for (int y = 0; y < h; y++) {
        for (int x = 0; x < w; x++) {
            int idx_src = y * w + x;
            int idx_dst = y * w + (w - x - 1);  // 水平翻转
            dst_buffer[idx_dst] = src_buffer[idx_src];
        }
    }
}

// 带透明度的图像绘制
inline void putimage_alpha(const Camera& camera,
    int dst_x, int dst_y, IMAGE* img) {
    int w = img->getwidth();
    int h = img->getheight();
    const Vector2& pos_camera = camera.get_position();
    AlphaBlend(GetImageHDC(GetWorkingImage()),
        (int)(dst_x - pos_camera.x),
        (int)(dst_y - pos_camera.y), w, h,
        GetImageHDC(img), 0, 0, w, h,
        { AC_SRC_OVER, 0, 255, AC_SRC_ALPHA });
}

// 生成素描图像（用于受伤闪烁效果）
inline void sketch_image(IMAGE* src, IMAGE* dst) {
    int w = src->getwidth();
    int h = src->getheight();
    Resize(dst, w, h);
    DWORD* src_buffer = GetImageBuffer(src);
    DWORD* dst_buffer = GetImageBuffer(dst);
    for (int y = 0; y < h; y++) {
        for (int x = 0; x < w; x++) {
            int idx = y * w + x;
            // 保留Alpha通道，将颜色设为白色
            dst_buffer[idx] = BGR(RGB(255, 255, 255)) |
                             (src_buffer[idx] & 0xFF000000);
        }
    }
}
```

## 5. 代码细节分析

### 5.1 物理引擎实现

**核心代码**：`player.h:358-405`

```cpp
void move_and_collide(int delta) {
    float last_velocity_y = velocity.y;

    // 1. 应用重力
    velocity.y += gravity * delta;
    position += velocity * (float)delta;

    // 2. 平台碰撞检测
    if (velocity.y > 0) {  // 只在下落时检测
        for (const Platform& platform : platform_list) {
            const Platform::CollisionShape& shape = platform.shape;

            // AABB碰撞检测
            bool is_collide_x = (max(position.x + size.x, shape.right) -
                                min(position.x, shape.left))
                                <= size.x + (shape.right - shape.left);
            bool is_collide_y = (shape.y >= position.y &&
                                shape.y <= position.y + size.y);

            if (is_collide_x && is_collide_y) {
                float delta_pos_y = velocity.y + delta;
                float last_tick_foot_pos_y = position.y + size.y - delta_pos_y;

                // 确保上一帧在平台上方
                if (last_tick_foot_pos_y <= shape.y) {
                    position.y = shape.y - size.y;  // 修正位置
                    velocity.y = 0;  // 停止下落

                    if (last_velocity_y != 0)
                        on_land();  // 触发落地事件

                    break;
                }
            }
        }
    }

    // 3. 子弹碰撞检测
    if (!is_invulnerable) {
        for (Bullet* bullet : bullet_list) {
            if (!bullet->get_valid() ||
                bullet->get_collide_target() != id) continue;

            if (bullet->check_collision(position, size)) {
                make_invulnerable();
                bullet->on_collide();
                bullet->set_valid(false);
                hp -= bullet->get_damage();
                last_hurt_direction = bullet->get_position() - position;

                if (hp <= 0) {
                    // 死亡击飞效果
                    velocity.x = last_hurt_direction.x < 0 ? 0.35f : -0.35f;
                    velocity.y = -1.0f;
                }
            }
        }
    }
}
```
